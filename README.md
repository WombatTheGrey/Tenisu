# Tenisu API
started as a simple technical test project but turned into a learning experience and a showcase project. 

What it does :
It's a very simple application to manage tenis players and compute some simple stats.

What it is : 
A .Net 10 application that built following the principles of DDD, using Entity framework for the persistance layer.
I used it as a learning opportunity and tried to respect the most recent standards.
